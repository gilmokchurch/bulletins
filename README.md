# 길목교회 주보 사본

길목교회 블로그(https://thewaynews.tistory.com)에 올라온 주보 PDF의 사본입니다.
홈페이지(https://theway.news/bulletin)에서 주보를 빨리 띄우려고 둡니다.

- `pdf/<블로그 글 번호>.pdf` — 주보 파일
- 매시간 GitHub Actions(`.github/workflows/sync.yml`)가 `sync.py`로 새 주보를 복사해 GitHub Pages로 내보냅니다.
- 3개월(92일)이 지난 주보 사본은 자동으로 지웁니다. 지운 주보는 홈페이지에서 블로그 파일을 거쳐 (조금 느리게) 열립니다.
- 블로그에서 주보 파일을 고쳐 다시 올렸다면, 여기서 해당 `pdf/<글 번호>.pdf`를 지우면 다음 실행 때 새로 복사됩니다.
- 직접 실행: 저장소의 **Actions → 주보 복사 → Run workflow**

## 온라인주보 (예배순서·광고)

홈페이지의 온라인주보(https://theway.news/online)가 읽는 자료입니다.

- `order/<글 번호>.json` — 그 주의 예배순서(가사·교독문·성경 본문 포함)와 공동체 소식
- `order/index.json` — 지난 주보 목록 (최신순). PDF는 3개월 뒤 지워져도 이 자료는 계속 남습니다.
- `order.py`가 주보 PDF 2~3쪽(예배순서), 4쪽(성경말씀: 개역개정·메시지 본문), 8쪽(공동체 소식)을 읽어 만듭니다.
- **금요일 오후 4시 ~ 토요일 밤 11시(한국 시간)에 30분마다** `.github/workflows/find.yml`이 새 주보를 찾고,
  이번 주일 주보를 찾은 뒤에는 바로 끝냅니다. 다른 요일에 올라온 주보는 매시간 복사 작업이 같이 처리합니다.
- 주보를 고쳐 다시 올렸다면 `pdf/<글 번호>.pdf`와 `order/<글 번호>.json`을 함께 지우세요.
- 주보 틀(묶음 제목 글꼴, '이름 ···· 내용 ···· 담당' 점선 줄)이 크게 바뀌면 `order.py`를 고쳐야 할 수 있습니다.
- 직접 실행: **Actions → 이번 주 주보 찾기 → Run workflow**
